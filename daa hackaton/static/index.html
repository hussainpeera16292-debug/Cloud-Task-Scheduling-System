1. Formal DAA Problem Formulation

Problem Statement: Given a set of \(N\) independent computational tasks \(\mathcal{T} = \{T_1, T_2, \dots, T_N\}\) and \(M\) parallel heterogeneous machines \(\mathcal{M} = \{M_1, M_2, \dots, M_M\}\).

Each task \(T_i = (p_i, e_i, d_i, r_i)\) has:

  • Priority \(p_i \in [1, 5]\): Criticality weight (5 = Critical, 1 = Low).
  • Burst Execution Time \(e_i > 0\): Processing cycles required.
  • Deadline \(d_i > 0\): Hard/soft time constraint before which task must finish.
  • Release / Arrival Time \(r_i \ge 0\): Earliest time task becomes available for scheduling.

Each machine \(M_j\) has speed multiplier \(s_j\). Effective runtime: \(e_{i,j} = \frac{e_i}{s_j}\).

Multi-Objective Optimization Goals

🎯 1. Minimize Weighted Tardiness

$$\min \sum_{i=1}^N p_i \cdot \max(0, C_i - d_i)$$

Penalizes missing urgent, high-priority tasks severely.

⏱️ 2. Minimize Makespan

$$\min \max_{j \in [1, M]} C_{\max, j}$$

Minimizes the overall completion time of the entire task batch.

⚖️ 3. Maximize Machine Balance

$$\min \sigma(\text{Busy}_1, \dots, \text{Busy}_M)$$

Avoids machine starvation and hotspot bottlenecks.

Dynamic Composite Greedy (DCG) Greedy + Min-Heap O(N log N + N log M) O(N + M) High-throughput cloud clusters with dynamic arrivals & mixed priorities.
Earliest Deadline First (EDF) Real-Time Greedy O(N log N + N · M) O(N + M) Strict real-time systems under non-overloaded operating conditions.
High-Priority First (HPF) Priority Queue O(N log N + N · M) O(N + M) Mission-critical systems where Priority 5 jobs cannot ever be delayed.
Shortest Processing Time (SPT) Greedy (SJF) O(N log N + N · M) O(N + M) Interactive servers maximizing job throughput and minimizing waiting time.

Genetic Algorithm (GA) Evolutionary Metaheuristic O(G · P · N · M) O(P · N) High-dimensional NP-hard scheduling where heuristic search gets stuck.

3. DAA Viva Preparation & Defense Questions

Q1: Why is Multi-Machine Scheduling with Deadlines NP-hard?

Even without deadlines or priorities, parallel machine makespan minimization (P || Cmax) is reducible from the classic NP-complete Partition Problem. Introducing release dates and deadline constraints creates strongly NP-hard optimization.

Q2: Why does pure Earliest Deadline First (EDF) fail when overloaded?

Under overloaded conditions (Domino effect), EDF continuously prioritizes tasks that are already doomed to miss their deadlines or have zero slack, leading to a cascade of missed deadlines. Our Dynamic Composite Greedy solves this by balancing slack with priority weight and SJF burst.

Q3: How does the Branch and Bound bounding function work?

We calculate a Lower Bound on partial schedules: \(LB = \text{CurrentPenalty} + \sum_{remaining} \min(p_i \cdot \text{slack})\). If \(LB \ge \text{BestUpperBound}\), the entire subtree is immediately pruned without traversing its \(M^k\) descendants.

Q4: What data structures ensure efficient execution?

We utilize binary min-heaps (priority queues) to maintain machine availability times in \(O(\log M)\) and sort ready task pools in \(O(N \log N)\), eliminating expensive \(O(N \cdot M)\) linear scans.
